# WhisperPaw shell completions

Auto-generated completion files for the `paw-*` tools.

## What is this

A completion file tells your shell what flags each `paw-*` command
accepts, so that pressing <kbd>Tab</kbd> after `paw-read --<tab>`
suggests `--rate`, `--volume`, `--max-chars`, etc. The completions
are **derived from each tool's argparse parser at build time**, so
adding a new flag to a tool is automatically reflected in the next
generated file.

## Supported shells

| Shell | File |
| --- | --- |
| bash  (≥ 3.2) | `whisperpaw.bash` |
| zsh           | `whisperpaw.zsh` |
| fish          | `whisperpaw.fish` |
| nushell       | `whisperpaw.nu` |

## Install (static files)

The static files in this directory are byte-identical to the live
output of `paw-complete <shell>`. Pick whichever shell you use.

### bash

```sh
# Either source it from your .bashrc:
echo 'source /path/to/WhisperPaw/completions/whisperpaw.bash' >> ~/.bashrc

# Or, after re-installing the package, just `eval` the live output:
echo 'eval "$(paw-complete bash)"' >> ~/.bashrc
```

### zsh

```sh
# Copy into any directory on your $fpath (e.g. ~/.zfunc) and make sure
# `autoload -U compinit && compinit` is in your .zshrc.
mkdir -p ~/.zfunc
cp completions/whisperpaw.zsh ~/.zfunc/_paw
```

### fish

```sh
# Fish auto-loads completions from ~/.config/fish/completions/:
cp completions/whisperpaw.fish ~/.config/fish/completions/paw-read.fish
```

(The `paw-read.fish` filename is fine — fish doesn't care about the
filename as long as the `complete -c paw-read …` directives inside
point at the right command. The contents cover `paw-read`, `paw-sound`,
`paw-watch`, and `paw-zoom`.)

### nushell

```sh
# Add the contents of whisperpaw.nu to your config.nu, or `source` it:
echo 'source /path/to/WhisperPaw/completions/whisperpaw.nu' >> \
    ~/.config/nushell/config.nu
```

## Install (live generator)

If you have the package installed, every shell can also use the
live generator instead of the static file. This means completions
are always in sync with the installed version of WhisperPaw:

```sh
# bash
echo 'eval "$(paw-complete bash)"' >> ~/.bashrc

# zsh — `paw-complete zsh > ~/.zfunc/_paw` works, but bash is faster
# to re-source on every shell start.

# fish
paw-complete fish > ~/.config/fish/completions/paw-read.fish

# nushell
paw-complete nu >> ~/.config/nushell/config.nu
```

## How it works

Each `paw-*` tool exposes a `build_parser()` function that returns
an `argparse.ArgumentParser`. The completion generator in
`whisperpaw/_completions.py` introspects that parser, extracts every
flag (long and short), its help text, and the choices for any
positional, then emits shell-specific code.

Adding a new flag to a tool needs no completion update — re-run the
generator and the new flag appears automatically.

## Verifying the static files are in sync

`tests/test_completions.py` contains a parametrized test that
asserts each static file in this directory is byte-identical to the
live `render()` output. If you add a new flag and forget to
regenerate, the test fails with a clear "regenerate it" message.

To regenerate after a flag change:

```sh
for shell in bash zsh fish nu; do
    python -c \
        "from whisperpaw._completions import render; \
         import sys; sys.stdout.write(render('$shell'))" \
        > completions/whisperpaw.$shell
done
```
